# Security Policy

## Supported Versions

Only the latest stable release of AegisScan receives active security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As a cybersecurity project, we take software vulnerabilities and security defects very seriously.

If you believe you have found a security vulnerability in AegisScan:

1. **Please do NOT open a public GitHub issue.**
2. Send an email with reproduction steps and proof of concept to **fredapacitan@gmail.com** or use GitHub's private vulnerability reporting feature on the repository.
3. Include:
   - Type of vulnerability
   - Step-by-step instructions to reproduce
   - Potential impact
   - Suggested fix (if any)

We will acknowledge receipt within 48 hours and work on a coordinated disclosure and patch.
